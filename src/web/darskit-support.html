DarsKit support

Quick checks

  • Open a fixed-page A4 design before generating a document.
  • If file import fails, confirm the file is a supported type and under 20 MB.
  • If a generated document is incomplete, shorten very long source text and try again.
  • Review the lesson topic, grade level, and document type before generating.

Supported source files

TXT, MD, text-based PDF, DOCX, CSV, JSON, HTML, and XML are supported in the current version.

Report a problem

You can report a reproducible DarsKit issue through the public Ghaith Web GitHub issue tracker. Include the Canva design type, the document type selected in DarsKit, what you expected, and what happened. Do not include sensitive student information.

DarsKit

Create editable lesson plans, worksheets, assessments, and answer keys in Arabic, French, or English—directly inside Canva.

What it does

  • Generates editable teaching documents in Arabic, French, or English for A4 designs.
  • Matches the output language to the lesson title automatically or lets the teacher select it manually.
  • Supports multiple document types, lesson durations, differentiation paths, and visual styles.
  • Accepts pasted source text and supported document files.
  • Does not require a separate DarsKit account in the current version.

DarsKit is designed for teacher workflows. Generated materials should be reviewed by the teacher before classroom use.
